# Riccio Advocacia

Crie um site profissional para um escritório de advocacia focado em Direito do Consumidor, com visual moderno, confiável e institucional.

Objetivo principal:
Levar o visitante a escolher o tipo de problema que deseja resolver e, em seguida, entrar em um fluxo inteligente de perguntas, semelhante a um mini formulário conversacional (estilo chatbot ou wizard), para coletar informações detalhadas do caso.

Estrutura do site:

Página inicial com:

Headline forte: “Defenda seus Direitos como Consumidor com Apoio Jurídico Especializado”

Subtítulo de autoridade e confiança

Botão de CTA: “Iniciar Atendimento”

Página de escolha do tipo de ação (Direito do Consumidor):
Exibir opções em formato de cartões clicáveis:

Problemas com compras online

Produto com defeito

Cobrança indevida

Cancelamento de serviços

Nome negativado indevidamente

Problemas com garantia

Golpes e fraudes

Outras situações

Ao clicar em uma opção, iniciar um fluxo de perguntas dinâmico:

Perguntas base que o sistema deve fazer:

O que aconteceu? (campo aberto)

Quando ocorreu o problema?

Nome da empresa envolvida

Valor aproximado do prejuízo

Você possui provas? (sim/não)

Se sim: permitir upload de arquivos (fotos, prints, PDFs)

Após o questionário:

Tela de agradecimento

Aviso de confidencialidade

Botão para agendamento de atendimento via WhatsApp ou formulário

Requisitos técnicos:

Sistema deve salvar as respostas em um painel interno ou enviar para e-mail

Interface simples, elegante e responsiva

Linguagem clara e acolhedora

Estrutura preparada para futura expansão para outras áreas do direito

Diferencial:
Criar experiência fluida, como uma conversa guiada, sem parecer um formulário tradicional.
